Malaria information and patient record system

Desktop application in Java

A desktop system for clinics that keeps patient malaria records and answers malaria questions from a built-in knowledge base of 27 concepts and 21 relationships. A 12-question symptom checker scores a patient's risk as low, moderate or high, and any severe danger sign triggers an urgent-care warning straight away.

Staff, admins and patients get different access. Records can be exported to another institution as a package with a SHA-256 checksum, and a tampered file is rejected on import. Every login and transfer goes into an audit log.

Java, Java Swing, Rule-Based Reasoning, RBAC, Password Hashing, Audit Logging

Niger Delta University chatbot

Browser app in JavaScript

A chatbot that answers questions about the university, such as faculties, departments, admissions, postgraduate study and student services. It has no server and no AI service. It works out what the student is asking, expands synonyms, and tolerates typos with edit-distance matching before searching 12 JSON files of university data.

I also compiled a bank of 423 test questions across 29 topics and wrote a Python script that turns it into JSON, plus a validator that checks the data files.

JavaScript, HTML, CSS, JSON, Python

Malaria Anthology

Content website in PHP and MySQL

A publishing site that collects malaria research, case studies and personal accounts, organised by category and searchable by title, summary and full text. Editors write, edit, publish and archive articles from an admin area, and only admins can manage categories and users.

Database queries use prepared statements, passwords are hashed, and all output is escaped to prevent injection and script attacks.

PHP, MySQL, HTML, CSS, RBAC, Password Hashing
